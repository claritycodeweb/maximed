# DANIBERT Site — Claude Code Guidelines

## Project overview
Personal advisory website for Maxime Danibert (danibert.ch). Bilingual (EN/FR) React SPA deployed on Vercel.

## Tech stack
- **Framework**: React 18 + Vite 5
- **Styling**: Tailwind CSS v3 (utility-first, no separate CSS files)
- **Routing**: React Router v6 with language-prefixed paths (`/` for FR, `/en` for EN)
- **i18n**: react-i18next with JSON locale files (`src/locales/en.json`, `src/locales/fr.json`)
- **SEO**: react-helmet-async for meta tags; static `sitemap.xml` and `robots.txt` in `public/`
- **Deployment**: Vercel with SPA fallback rewrites in `vercel.json`

## Directory structure
```
src/
├── components/       # Reusable UI components (Header, Footer, SocialLinks, etc.)
├── pages/            # Route-level page components (Home, PrivacyPolicy, TermsAndConditions, NotFound)
├── locales/          # Translation JSON files (en.json, fr.json)
├── hooks/            # Custom hooks (useSEO, useLanguage)
├── i18n.js           # i18next configuration
├── App.jsx           # Router setup, layout, scroll/language sync
├── main.jsx          # Entry point
└── index.css         # Tailwind directives
public/
├── robots.txt
├── sitemap.xml
└── danibert_logo.svg
```

## Key conventions
- All user-visible text must come from locale JSON files — never hardcode strings.
- FR is the default/fallback language. EN routes are prefixed with `/en`.
- Language detection order: URL path > cookie > navigator.
- Pages use code splitting via `React.lazy` + `Suspense`.
- Legal pages (Privacy Policy, Terms) store content as HTML strings in locale JSON and render with `dangerouslySetInnerHTML`.
- The contact form POSTs to `/api/contact` — this endpoint must be configured on the hosting side.
- All external links use `rel="noopener noreferrer" target="_blank"`.

## Adding a new page
1. Create a page component in `src/pages/`.
2. Add routes for both EN and FR in `src/App.jsx`.
3. Add translations in both `en.json` and `fr.json`.
4. Update `useLanguage.js` ROUTE_MAP and `useSEO.jsx` ALT_PATHS.
5. Add entries to `public/sitemap.xml`.

## SEO checklist for changes
- Every page must use the `<SEO>` component with title, description, and page key.
- Canonical and hreflang alternate links are auto-generated by `useSEO`.
- JSON-LD structured data is on the Home page only.
- Update `sitemap.xml` when adding/removing pages.
